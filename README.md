## About this mod

CIT Resewn 9minecraft Mod brings OptiFine-style Custom Item Textures to Minecraft, letting resource packs give your items brand-new looks - no OptiFine required. It reads the same MCPatcher/OptiFine CIT format, so a single item can change its texture, model, or even armor and elytra appearance based on its name, lore, damage, stack size, NBT, or enchantments.
